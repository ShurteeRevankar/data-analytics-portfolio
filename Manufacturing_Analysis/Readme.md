# Manufacturing Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing manufacturing operations and production performance using Power BI. The dashboard provides insights into production efficiency, quality control, machine utilization, employee productivity, and wastage monitoring to support data-driven decision-making.

## 🎯 Objective

### The main objectives of this project are:

- Monitor manufacturing performance and production efficiency.
- Track manufactured, processed, and rejected quantities.
- Analyze machine, employee, and department performance.
- Identify wastage trends and operational bottlenecks.
- Improve overall operational effectiveness through data insights.

## 📊 Business Requirements

The dashboard was developed to address the following business needs:

- Production Monitoring
- Quality & Rejection Analysis
- Department Performance Tracking
- Machine Utilization Analysis
- Employee Productivity Analysis
- Wastage Monitoring
- Trend Analysis & Forecast Reporting

## 🛠 Tools & Technologies
- Power BI – Data Visualization & Dashboard Development
- SQL – Data Extraction & Transformation
- Microsoft Excel – Data Cleaning & Preprocessing

## 💡 Recommendations
- Implement stricter quality control checks to reduce rejection rates.
- Improve machine maintenance and efficiency.
- Monitor and minimize wastage-generating operations.
- Optimize department productivity through performance tracking.
- Use trend analysis for proactive production planning.

## 🚀 Project Outcomes
- Centralized manufacturing performance monitoring.
- Improved visibility into production and quality metrics.
- Better decision-making through real-time insights.
- Enhanced operational efficiency and cost optimization.
