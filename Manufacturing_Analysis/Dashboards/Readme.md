# Dashboard

## 📈 Dashboard Features

Executive Manufacturing Dashboard. 
Provides a high-level overview of manufacturing performance and operational KPIs.

- Production & Rejection Analysis
- Manufactured Quantity Tracking
- Processed Quantity Tracking
- Rejected Quantity Analysis
- Rejection Trend Monitoring
- Manufacturing Analytics View
- Department-wise Performance Analysis
- Machine Utilization Monitoring
- Employee Productivity Assessment
- Production Trend Analysis

## 📌 Key Performance Indicators (KPIs)

- Manufactured Quantity
- Processed Quantity
- Rejected Quantity
- Wastage Percentage
- Machine Cost
- Cost Per Unit

## 🔍 Key Insights
- Identification of major rejection sources.
- Comparison of department-wise performance.
- Monitoring production trends over time.
- Analysis of machine efficiency and utilization.
- Tracking employee productivity.
- Detection of high-wastage production processes.
